# Анализ системы управления

## Общие сведения

Рассмотрим структурную схему системы автоматического управления.
Основное уравнение динамики имеет вид:

$$J\frac{d\omega}{dt} = M - M_c$$

где $J$ — момент инерции, $\omega$ — угловая скорость,
$M$ — движущий момент, $M_c$ — момент сопротивления.

Программа реализована на языке Python:

def compute_omega(J, M, Mc, dt):
    return (M - Mc) / J * dt
