# Введение

Целями выполнения данной лабораторной работы являются: изучение метода Гаусса и его модификаций, составление алгоритма метода и программы его реализации, получение численного решения заданной СЛАУ, а также выполнение тестовых примеров и проверка правильности работы программы.

Система линейных алгебраических уравнений (СЛАУ)[^1] — одна из наиболее часто встречающихся вычислительных задач. Значительная часть численных методов решения различных по своей природе задач (в особенности нелинейных) включает в себя решение систем линейных уравнений как элементарный шаг соответствующего алгоритма.

Одна из трудностей практического решения систем большой размерности связана с ограниченностью оперативной памяти ЭВМ и с ростом числа арифметических операций. Значительная часть прикладных задач приводит к матрицам, в которых число ненулевых элементов много меньше общего числа элементов матрицы. Такие матрицы принято называть разреженными. Прямые методы дают в принципе точное решение (если не учитывать ошибок округления) за конечное число арифметических операций. Для хорошо обусловленных систем небольшого порядка ($n \le 200$) применяются практически только прямые методы. Наибольшее распространение среди прямых методов получил метод Гаусса и его модификации, рассматриваемые в настоящей работе.

[^1]: Под СЛАУ понимается система уравнений вида $Ax = b$, где $A$ — квадратная матрица коэффициентов, $x$ — вектор неизвестных, $b$ — вектор свободных членов.

# Теоретические сведения

СЛАУ обычно записывается в виде

$$\sum_{j=1}^{n} a_{ij} x_j = b_i, \quad 1 \le i \le n,$$

или коротко

$$Ax = b,$$

где $A$ — матрица коэффициентов, $x$ — вектор неизвестных, $b$ — вектор свободных членов.

Одним из самых распространённых прямых методов решения СЛАУ является метод Гаусса. Вычисления с помощью метода Гаусса заключаются в последовательном исключении неизвестных для преобразования системы к эквивалентной системе с верхней треугольной матрицей. Вычисления значений неизвестных производят на этапе обратного хода.

## Схема единственного деления

Прямой ход состоит из $n-1$ шагов. На $k$-м шаге из уравнений с номерами $i = k+1, \dots, n$ исключается неизвестное $x_k$. Для этого вычисляются множители

$$q_{ik} = \frac{a_{ik}^{(k-1)}}{a_{kk}^{(k-1)}},$$

и из $i$-го уравнения вычитается $k$-е уравнение, умноженное на $q_{ik}$:

$$a_{ij}^{(k)} = a_{ij}^{(k-1)} - q_{ik} a_{kj}^{(k-1)}, \qquad b_i^{(k)} = b_i^{(k-1)} - q_{ik} b_k^{(k-1)}.$$

Обратный ход позволяет найти неизвестные:

$$x_n = \frac{b_n^{(n-1)}}{a_{nn}^{(n-1)}},$$

$$x_k = \frac{b_k^{(k-1)} - \sum_{j=k+1}^{n} a_{kj}^{(k-1)} x_j}{a_{kk}^{(k-1)}}.$$

Недостаток схемы единственного деления состоит в том, что если главный элемент $a_{kk}^{(k-1)}$ близок к нулю или равен ему, метод может дать большую погрешность или оказаться нереализуемым.

## Метод Гаусса с выбором главного элемента по столбцу

На $k$-м шаге в качестве ведущего выбирается максимальный по модулю коэффициент $a_{ik}$ в столбце $k$ среди строк $i = k+1, \dots, n$. Соответствующее уравнение меняется местами с $k$-м. Это гарантирует, что все множители удовлетворяют условию $|q_{ik}| \le 1$, что предотвращает неконтролируемый рост погрешности. Остальные действия совпадают со схемой единственного деления.

## Метод Гаусса с выбором главного элемента по всей матрице

На $k$-м шаге максимальный по модулю элемент ищется среди всех элементов подматрицы, начиная со строки $k$ и столбца $k$. Найденный элемент меняется местами с текущим ведущим элементом, что требует перестановки как строк, так и столбцов (с соответствующей перенумерацией неизвестных). На этапе обратного хода неизвестные вычисляются в порядке, определяемом перестановкой столбцов. Это наиболее устойчивый, но и более трудоёмкий вариант метода.

# Программная реализация

Для реализации использовался язык программирования Python. Программа построена на основе объектно-ориентированного подхода и включает в себя следующие компоненты:

- абстрактный базовый класс LSSolver, определяющий общий интерфейс решателей;
- класс LinearSystem, инкапсулирующий матрицу системы, вектор правой части и вспомогательные операции (проверка невязки, вычисление числа обусловленности, создание копии);
- иерархию решателей GaussSolverNoPivot, GaussSolverRowPivot, GaussSolverFullPivot, реализующих соответственно метод Гаусса без выбора ведущего элемента, с частичным выбором (по столбцу) и с полным выбором (по всей матрице);
- класс NumpySolver — обёртку над numpy.linalg.solve для верификации результатов.

Базовый класс GaussSolver содержит общий каркас прямого хода, обратного хода и учёта перестановок столбцов; конкретные решатели переопределяют только стратегию выбора ведущего элемента. Это позволяет избежать дублирования кода и делает реализацию компактной и расширяемой.

Фрагмент листинга, реализующий прямой и обратный ход метода Гаусса:
```python
class GaussSolver(LSSolver, ABC):

    def __init__(self, atol: float = 1e-12):
        self.atol = atol

    def solve(self, ls: LinearSystem) -> np.ndarray:
        A = ls.A.astype(np.float64).copy()
        b = ls.b.astype(np.float64).copy()

        was_1d = (b.ndim == 1)
        if was_1d:
            b = b.reshape(-1, 1)

        col_perm = np.arange(A.shape[0])

        A, b, col_perm = self._forward_elimination(A, b, col_perm)
        x = self._back_substitution(A, b)
        x = self._undo_column_permutation(x, col_perm)

        return x.ravel() if was_1d else x

    @abstractmethod
    def _select_pivot(self, A: np.ndarray, k: int) -> tuple[int, int]:
        ...

    def _forward_elimination(self, A, b, col_perm):
        pivot_tol = self.atol
        n = A.shape[0]

        for k in range(n - 1):
            pivot_row, pivot_col = self._select_pivot(A, k)

            if abs(A[pivot_row, pivot_col]) < pivot_tol:
                raise np.linalg.LinAlgError(
                    "Матрица вырождена: ведущий элемент близок к нулю."
                )

            if pivot_row != k:
                A[[k, pivot_row], :] = A[[pivot_row, k], :]
                b[[k, pivot_row], :] = b[[pivot_row, k], :]

            if pivot_col != k:
                A[:, [k, pivot_col]] = A[:, [pivot_col, k]]
                col_perm[[k, pivot_col]] = col_perm[[pivot_col, k]]

            for i in range(k + 1, n):
                factor = A[i, k] / A[k, k]
                A[i, k:] -= factor * A[k, k:]
                b[i, :] -= factor * b[k, :]
            A[k + 1:, k] = 0.0

        if abs(A[n - 1, n - 1]) < pivot_tol:
            raise np.linalg.LinAlgError(
                "Матрица вырождена: ведущий элемент близок к нулю."
            )

        return A, b, col_perm

    def _back_substitution(self, A, b):
        n = A.shape[0]
        m = b.shape[1]
        x = np.zeros((n, m), dtype=np.float64)

        for i in range(n - 1, -1, -1):
            s = b[i, :] - A[i, i + 1:] @ x[i + 1:, :]
            x[i, :] = s / A[i, i]

        return x
```

## Листинг иерархии решателей
```python
class GaussSolverNoPivot(GaussSolver):
    def _select_pivot(self, A, k):
        return k, k

class GaussSolverRowPivot(GaussSolver):
    def _select_pivot(self, A, k):
        pivot_row = k + int(np.argmax(np.abs(A[k:, k])))
        return pivot_row, k

class GaussSolverFullPivot(GaussSolver):
    def _select_pivot(self, A, k):
        sub = np.abs(A[k:, k:])
        i, j = np.unravel_index(int(np.argmax(sub)), sub.shape)
        return k + int(i), k + int(j)
```
## Листинг класса LinearSystem
```python
import numpy as np
from typing import TYPE_CHECKING

if TYPE_CHECKING:
    from LSSolver import LSSolver

class LinearSystem:
    def __init__(self, A, b, rtol=1e-8, atol=1e-12):
        self.rtol = rtol
        self.atol = atol
        self.A = np.array(A, dtype=np.float64)
        self.b = np.array(b, dtype=np.float64)
        self._validate_inputs()

    def _validate_inputs(self):
        if self.A.ndim != 2:
            raise ValueError("Матрица A должна быть двумерной.")
        if self.A.shape[0] != self.A.shape[1]:
            raise ValueError("Матрица A должна быть квадратной.")
        if self.A.shape[0] != self.b.shape[0]:
            raise ValueError(
                "Размерность вектора b должна совпадать с числом строк A."
            )

    def solve(self, solver: 'LSSolver'):
        try:
            x = solver(self.copy())
            return x
        except np.linalg.LinAlgError:
            raise ValueError(
                "Система не имеет единственного решения (матрица A вырождена)."
            )

    def check_residual(self, x, rtol=None, atol=None):
        if rtol is None:
            rtol = self.rtol
        if atol is None:
            atol = self.atol
        b_pred = np.dot(self.A, x)
        is_correct = np.allclose(b_pred, self.b, rtol=rtol, atol=atol)
        residual = np.abs(b_pred - self.b)
        return is_correct, residual

    def get_condition_number(self):
        return np.linalg.cond(self.A)

    def copy(self, rtol=None, atol=None) -> 'LinearSystem':
        A = self.A.copy()
        b = self.b.copy()
        if rtol is None:
            rtol = self.rtol
        if atol is None:
            atol = self.atol
        return LinearSystem(A, b, rtol, atol)
```
## Листинг класса NumpySolver
```python
import numpy as np
from LSSolver import LSSolver
from LineSystem import LinearSystem

class NumpySolver(LSSolver):
    """Решатель СЛАУ на основе np.linalg.solve."""

    def solve(self, ls: LinearSystem) -> np.ndarray:
        return np.linalg.solve(ls.A, ls.b)
```

## Листинг абстрактного базового класса LSSolver
```python
from abc import ABC, abstractmethod
from typing import TYPE_CHECKING
import numpy as np

if TYPE_CHECKING:
    from LineSystem import LinearSystem

class LSSolver(ABC):
    """Абстрактный решатель СЛАУ."""

    @abstractmethod
    def solve(self, ls: 'LinearSystem') -> np.ndarray:
        """Возвращает решение x системы ls."""
        pass

    def __call__(self, ls: 'LinearSystem') -> np.ndarray:
        return self.solve(ls)
```
